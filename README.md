# サーモンランNW 武器チェッカー

スプラトゥーン3のサーモンランNW（ネクストウェーブ）で使用した武器を視覚的にチェックし、オカシラシャケの出現・討伐状況を記録できるWebツールです。

## 機能

### 武器チェック機能 (Phase 1)
- 全71種類の武器（通常武器63種 + クマサン印8種）をグリッド表示
- プラス/マイナスモードの切り替えによる使用回数のカウント
- 各武器の使用回数をバッジで表示（0回は非表示）
- 右クリック（スマホは長押し）で個別リセット
- 全クリア機能（確認ダイアログ付き）
- 統計表示（使用武器数、総使用回数、達成率）
- ツールチップで武器名表示
- データはlocalStorageに自動保存

### オカシラ連合記録機能 (Phase 2)
- ヨコヅナ、タツ、ジョーの3体を記録
- 出現回数・討伐回数をそれぞれカウント
- 討伐率の自動計算
- 個別リセット機能
- ヘッダーに総合オカシラ討伐率を表示

## 使い方

### 武器カウント
1. ヘッダーの「+」「-」ボタンでモードを切り替え
2. 武器カードをクリックでカウント増減
   - 「+」モード: クリックで+1
   - 「-」モード: クリックで-1（最小0）
3. 右クリック（スマホは長押し）で個別リセット

### オカシラ記録
1. 各オカシラカードの「+」「-」ボタンで出現・討伐回数を記録
2. 討伐率は自動計算されます
3. 「リセット」ボタンで個別にリセット可能

## デプロイ方法

### GitHub Pagesでの公開

1. このリポジトリをGitHubにプッシュ
2. リポジトリの Settings > Pages に移動
3. Source で "Deploy from a branch" を選択
4. Branch で "main" と "/ (root)" を選択して Save
5. 数分後にサイトが公開されます

公開URL: `https://<username>.github.io/<repository-name>/`

### ローカルでの実行

1. ファイルをダウンロード
2. `index.html` をブラウザで開く

または、ローカルサーバーを起動:
```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合
npx serve
```

## 技術仕様

- 純粋なHTML/CSS/JavaScript（フレームワーク不使用）
- データ保存: localStorage API
- レスポンシブデザイン対応

### localStorage キー
- `splatoon3_salmon_usage_count`: 武器使用回数
- `splatoon3_salmon_boss_records`: オカシラ記録
